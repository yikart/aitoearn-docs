| --- | --- |

## Notes

Best practices to protect Facebook accounts and avoid being marked as spam:

When you share the same content to multiple Facebook Pages, posts sent at the same time may be flagged by Facebook as spam or bot behavior. This can cause posts to fail and access tokens to be revoked, requiring a channel refresh in Aitoearn. In some cases, Facebook may temporarily restrict the account.

Stagger publishing times across Pages, for example:
- Page 1: 09:30
- Page 2: 09:34
- Page 3: 09:39
- Page 4: 09:42
- Page 5: 09:47

# Facebook Error Library

When using a scheduling tool like Aitoearn, social networks may reject posts and return errors. Find the error below and follow the solution.

| Error | Cause | Solution |
| --- | --- | --- |
| "This channel has reached the daily posting limit." | The daily posting limit has been reached. | Reduce scheduled posts for the day and try again later. See the daily posting limit. |
| "Aitoearn lost authorization to post." | Facebook password changed recently, token expired, or permissions are insufficient. | Reauthorize. In Facebook Edit settings, select all required Pages and permissions, then refresh the connection in Aitoearn and retry. |
| "Please ensure you're an Admin for the FB Group and Aitoearn has been added as an app." | The authorized account is not a group admin or permissions are insufficient. | Confirm the authorized profile is still a group admin, add the Aitoearn app in Facebook group settings, then refresh the channel in the dashboard. |
| "Please ensure you are a Page admin and have two-factor authentication enabled." | The authorized account lacks permissions or 2FA is not enabled. | Confirm you have admin access to the Page and enable 2FA, then refresh the connection and retry. |
| "Trouble uploading media/image." | Unknown upload issue or image format/size does not meet requirements. | Retry publishing. Confirm the image is JPG/PNG/HEIC and &lt;=4MB. |
| "We're investigating a potential FB bug; the post may have been published." | Facebook publishing error, but the post may already be live. | Check Facebook.com first. If published, remove the failed item from the queue. Use native publishing temporarily if needed. |
| "Publishing Authorization is required." | Facebook requires publishing authorization for high-impact Pages. | Complete Facebook's publishing authorization, enable 2FA, confirm location services are enabled, and refresh the channel. |
| "Your content couldn't be shared because it goes against Community Standards." | The link was reported or considered non-compliant. | Try the same post directly on Facebook. If it still fails, appeal to Facebook. |
| "Log in to facebook.com and follow the prompts." | The account triggered a temporary security check. | Log in to Facebook and complete the prompt, then refresh the channel and retry. |
| "We're bumping into a few Facebook Page limits." | The Page triggered rate limits or had low engagement in the past 24 hours. | Temporarily reduce posting frequency, such as one post every 24 hours, and increase engagement before resuming scheduling. |
| "An unknown error has occurred." | Temporary unknown error. | Try again later. Contact support if it continues. |
| "Aitoearn doesn't have permission to post on your behalf." | Required permissions were not selected during connection. | Reauthorize and make sure all required Pages and permissions are selected, then refresh and retry. |

> Tip: When reauthorizing, make sure you are signed in with a Facebook profile that has admin access, and select all required Pages, groups, and permissions during authorization.
