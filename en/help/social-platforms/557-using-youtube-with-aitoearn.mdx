> Note: YouTube service is currently in beta. Features and permissions may change.

## Connection Requirements

- Sign in and connect with the Google account that owns the YouTube channel. Brand account admins are not currently supported.
- Complete YouTube email verification: unverified accounts can publish up to 10 posts within 24 hours and cannot add external links in descriptions. Verified accounts are not subject to this limit.

## Features and Good-to-Knows

| Item | Details |
| --- | --- |
| Schedule posts | Supports scheduling YouTube Shorts. |
| Daily posting limit | Users with unverified email addresses can publish up to 10 posts per day. Users with verified email addresses have no daily limit. |
| Character limit | Title limit: 100 characters. Description limit: 5,000 characters. |
| Hashtags | You can enter hashtags in the editor. After publishing, hashtags become clickable like native platform hashtags. |
| Thumbnail | Custom thumbnails are not currently supported for YouTube Shorts. |

## Publishing Requirements

| Content | Text only | Image | Video |

YouTube Shorts video specifications:

| Item | Video |
| --- | --- |
| Allowed per post | Up to 1 video |
| Video length | Up to 3 minutes |
| File size | 10GB or smaller |
| Dimensions / aspect ratio | Square 1:1 or vertical 9:16; vertical recommended |
| Supported formats | MOV, MP4, MPG, MPEG, AVI, WebM |
| Custom thumbnail | Not supported |
| Giphy and Canva integration | Not supported |
| Alt text | Not supported |

- Actual publishing depends on Aitoearn page validation.
