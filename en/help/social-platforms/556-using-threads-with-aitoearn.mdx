## Connection Requirements

Your Threads account must be linked to Instagram before it can connect to Aitoearn.

## Features and Good-to-Knows

| Item | Details |
| --- | --- |
| Schedule posts | Supports scheduling Threads posts. |
| Tags / mentions | To tag or mention another Threads or Instagram account, enter the full username. It becomes clickable after publishing. |
| Topics | Threads supports only 1 topic per post. Use `#` to create a topic. After publishing, the first word becomes the topic. Remove spaces for multi-word topics. Topics can include letters, numbers, and underscores, but cannot contain only numbers. |
| Character limit | Each message in the same thread can contain up to 500 characters. |
| Link limit | Each Threads post supports up to 5 links. Repeated links also count toward the total. |
| Emojis | Emojis are supported. |
| Link previews | The first link in the body generates a preview card when available. |
| Daily posting limit | Up to 250 posts every 24 hours. Each post in a multi-post thread counts toward the limit. |

## What if an Image Aspect Ratio Exceeds the Threads Range?

Meta Threads only accepts images with an aspect ratio between 1:10 and 10:1. That means the width cannot be more than 10 times the height, and the height cannot be more than 10 times the width.

If an image exceeds this range, Aitoearn flags it before publishing and prompts you to crop or replace it, helping prevent the post from getting stuck in "sending".

To calculate an image aspect ratio, divide width in pixels by height. For example, a 741 x 62 banner has an aspect ratio of 741/62 ≈ 11.95, which exceeds the accepted range. You can crop, compress, or re-export the image from the source tool.
