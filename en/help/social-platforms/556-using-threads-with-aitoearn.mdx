## Available Features

| Feature | Publishing | Analytics | Engagement |
| --- | --- | --- | --- |
| Supported | ✓ | ✓ | x |

## Connection Requirements

A Threads account must be linked to Instagram before it can connect to Aitoearn.

## Publishing Requirements

| Content | Text only | Image | Video |
| --- | --- | --- | --- |
| Supported | ✓ | ✓ | ✓ |

- Character limit: approximately 500 characters per post.
- Topic: only 1 topic, similar to a single hashtag, is supported per post.
- Links: the first link in the post generates a preview card when available.
- Emoji: supported.
- Multi-post Threads: up to 25 posts are supported on the web. Mobile is not currently supported.

| Category | Video | Image |
|--------------------------|----------------------------------------------------------------------|----------------------------------------|
| **Allowed per post** | 1 video | 20 images |
| **File size** | Up to 1GB, maximum 5 minutes, longer than 0 seconds | Up to 8MB |
| **Supported formats** | MOV or MP4 | JPG, PNG |
| **Custom thumbnail** | Not supported | Not supported |
| **Autoplay in feed** | Videos autoplay | - |
| **Alt text** | Not supported | Not supported |
| **Aspect ratio** | 9:16 | 10:1 |
| **Carousels** | Not supported | Minimum 2 images, maximum 10 images |
| **Frame rate** | 23–60 FPS | - |
| **Video bitrate** | VBR, up to 25Mbps | - |
| **Audio bitrate** | 128kbps | - |

> Threads does not currently support GIFs.

## Other Questions

### Valid Hashtag Rules

- A hashtag must begin with `#` and cannot contain only numbers, such as `#1`.
- A hashtag ends at a space, line break, `.`, `!`, `?`, `,`, `;`, `:`, `@`, or `&`.
