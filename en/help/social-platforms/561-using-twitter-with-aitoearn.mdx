## X/Twitter Publishing Requirements

| Content | Text only | Image | Video |
| --- | --- | --- | --- |
| Supported | ✓ | ✓ | ✓ |

| Category | Video | Image | GIF |
|--------------------------|----------------------------------------------------------------------|-----------------------|--------------------------------|
| **Allowed per post** | 1 video | 4 images | 1 GIF |
| **Video length** | Minimum 0.5 seconds, maximum 140 seconds<br />📝 X Premium/Twitter Blue subscribers can upload longer videos only when publishing natively on X/Twitter | - | - |
| **File size** | Up to 512MB | Up to 5MB | Up to 15MB |
| **Dimensions** | - | Up to 8192 × 8192px | Up to 1280 × 1080px<br />Maximum total pixels: 300 million |
| **Supported formats** | MP4, MOV, AVI, M4V<br />📝 Audio-only MP4 files are not supported and must contain video | JPG, PNG, HEIC, WebP | GIF |
| **Autoplay in feed** | Not supported | - | - |
| **Custom thumbnail** | Not supported | - | - |
| **Recommended frames** | ≤ 60 FPS | - | ≤ 350 frames |

- Daily posting limit: 100 posts every 24 hours.
- Character limits:
  - Free X users: 280 characters.
  - X Basic, Premium, and Premium+ users: 25,000 characters.*

### Additional GIF Requirements

If an animated GIF loses quality or returns an error, follow these requirements:
- Maximum GIF resolution: **1280 × 1080** (width × height).
- Maximum GIF frames: **350**.
- Maximum total GIF pixels: **width × height × frames ≤ 300 million**.
