## TikTok Publishing Requirements

| Content | Text only | Image | Video |
| --- | --- | --- | --- |
| Supported | x | ✓ | ✓ |

| **Item** | **Video** | **Image*** |
| -------- | --------- |
| **Per post** | 1 | Up to 10 |
| **Video length** | 3 seconds to 10 minutes | Not applicable |
| **File size** | 1GB or less, with a minimum height and width of 360px | Up to 20MB |
| **Dimensions/aspect ratio** | Minimum height and width of 360px | Maximum resolution: 1080 x 1920px or 1920 x 1080px |
| **Supported formats** | MOV, MP4, or WebM | JPG and WebP (HEIC and PNG are converted to JPG) |
| **Custom thumbnail** | The frame selected in the Aitoearn editor is used as the video thumbnail on the TikTok profile. | Not applicable |
| **Recommended frame rate** | 23 FPS to 60 FPS | Not applicable |
| **Autoplay** | Yes | Not applicable |
| **Canva integration** | No | Yes |
| **Alt text** | Alt text cannot be added to TikTok videos through Aitoearn. Learn more: [Adding alt text to images](https://aitoearn.帮助scoutdocs.com/article/618-添加ing-alt-text-到-您的-图片s). This is not supported due to API limitations. |

- Up to 25 posts every 24 hours.
- Up to 2,200 characters per post.
