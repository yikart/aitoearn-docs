## Features and Good-to-Knows

| Item | Details |
| --- | --- |
| Schedule posts (web) | Supports scheduling TikTok posts on web. |
| Schedule posts (mobile) | Supports scheduling TikTok posts on mobile. |
| Tags / mentions | To tag or mention another TikTok account, enter the exact username. It becomes clickable after publishing. |
| Hashtags | Each post can use up to 5 hashtags. Hashtags are not shown as links in the editor, but appear as links after publishing to TikTok. |
| Daily posting limit | Up to 25 posts every 24 hours. |
| Character limit | Each post can contain up to 2,200 characters. |
| Music, trending audio, stickers, or polls | Due to API limitations, TikTok audio library tracks, trending audio, stickers, and polls cannot currently be added directly. |

## TikTok Publishing Requirements

| Content | Text only | Image | Video |
| --- | --- | --- | --- |
| Supported | x | ✓ | ✓ |

| Item | Video | Image |
| --- | --- | --- |
| Allowed per post | Up to 1 | Up to 10 images |
| Video length | 3 seconds to 10 minutes | Not applicable |
| File size | Up to 1GB; width and height must both be &gt;=360px | Up to 20MB |
| Dimensions / aspect ratio | Width and height must both be &gt;=360px | Maximum resolution 1080 x 1920 or 1920 x 1080 |
| Supported formats | MOV, MP4, WebM | JPG, JPEG, WebP |
| Custom thumbnail | Supports selecting a frame from the video as the profile thumbnail | Not applicable |
| Best frame rate | 23 FPS to 60 FPS | Not applicable |
| Feed autoplay | Supported | Not applicable |
| Canva integration | Not supported | Supported |
| Alt text | Adding alt text to videos is not currently supported | Not supported due to API limitations |

- Actual publishing depends on Aitoearn page validation.
