When scheduling posts, keep in mind that each social network has its own character limits.  
The table below lists the maximum character count for common social platforms.

| Platform/channel | Character limit |
|-------------------------|----------|
| Facebook Pages and Groups | Post / Reel captions: 5,000 characters<br />First comments: 5,000 characters |
| Instagram accounts | Post / Reel captions: 2,200 characters<br />First comments: 2,200 characters<br />Story captions published by notification: 120 characters |
| X/Twitter profiles | Free accounts: 280 characters<br />Basic, Premium, and Premium+ accounts: 25,000 characters |
| LinkedIn Pages and profiles | Posts: 3,000 characters<br />First comments: 1,250 characters |
| Pinterest boards | 500 characters |
| TikTok accounts | 2,200 characters |
| Start Pages | 5,000 characters |
| Mastodon accounts | 500 characters |
| YouTube Shorts | 5,000 characters |
| Threads | Posts: 500 characters<br />Topics: 50 characters |
| Bluesky | 300 characters |
| Google Business Profiles | 1,500 characters |

## Notes

- Images may also take up character space. If the available character count goes down after you add an image, that platform counts images toward the character allowance, such as X/Twitter and LinkedIn.
- When publishing through a third-party tool, some API limits may be stricter than the native platform limits.
