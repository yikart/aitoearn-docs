When scheduling posts, note that each social network has its own character limits.

The table below lists the maximum character count for each platform.

| Platform/channel | Character limit |
|-------------------------|----------|
| Facebook Pages | Post/Reel description: 5,000<br />First comment: 5,000 |
| Instagram accounts | Post/Reel description: 2,200<br />First comment: 2,196 |
| X/Twitter profiles | Free users: 280 characters<br />Paid users (Basic, Premium, Premium+): 25,000 characters* |
| LinkedIn Pages and profiles | Post: 3,000<br />First comment: 1,248 |
| Pinterest boards | 500 |
| TikTok            | 2,200 |
| YouTube           | 5,000 |
| Threads | Post: 500<br />Topic: 50 |
