## Important Notes

- Keep promotional content for the period specified on the task page. Deleting it during the retention period may affect settlement.
- Keep likes, saves, comments, follows, and other required actions active for the specified period. Reversing them early may affect settlement.
- The platform counts only authentic, natural, and task-related valid actions.
- Complete identity verification on RedNote and other platforms when recommended to reduce account restrictions.

## Promotion Task Guide

1. Open the Task Marketplace and select a promotion task.

   ![Select a promotion task](/assets/help/a_step1.png)

   ![Accept a promotion task](/assets/help/a_step2.png)

2. Review the platform, content requirements, reward rules, and retention period. Confirm whether the task uses a recommended draft or original content.

   ![Review and submit promotion content](/assets/help/a_step3.png)

3. Publish before the submission deadline. You can connect a platform account for one-click publishing, or publish by scanning the QR code and then submit the post link.

   ![Publish promotion content](/assets/help/a_step5.png)

   The example below uses RedNote. Connect the RedNote account and authorize both the RedNote home page and Creator Center. Install the [AiToEarn browser extension](https://chromewebstore.google.com/detail/aitoearn-extension/hnmocdhmnfgcjnedmdgfefcobideaeja) first. See the [extension guide](https://aitoearn.cn/zh-CN/websit/plugin-guide) for installation instructions.

   ![Authorize RedNote and RedNote Creator Center](/assets/help/a_step4.png)

4. Keep the content for the required period and wait for data collection and settlement.

   ![Promotion task completed](/assets/help/a_step6.png)

## FAQ

### What should I do if AI review fails for an engagement task?

Confirm that you completed the correct action on the specified post and uploaded a clear screenshot. Comments must be authentic and relevant. If the result is correct but review still fails, select **Cancel Task Submission** on the task details page and submit it again. If the result still differs from what you expected, select **Request Manual Review** or **Submit a Ticket**.

### What should I do if the Chrome Web Store is unavailable or the browser extension cannot be installed?

See the [extension guide](https://aitoearn.cn/zh-CN/websit/plugin-guide) and choose an installation method available to you.
