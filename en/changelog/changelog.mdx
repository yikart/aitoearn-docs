# 🚀 AiToEarn 2.0.65

### 🎬 快速视频生成全新登场

* **一种全新的视频创作方式上线**：平台新增快速视频生成能力，支持多场景编排、智能语音配音和一键成片，帮助创作者高效产出竖版短视频。
* **灵活的场景素材组合**：每个视频可由静态文字、图片或视频片段混合构成，满足产品展示、口播讲解等不同创意需求。
* **双重分辨率适配多平台**：创作者可自由选择 720p 或 480p 输出，平衡画质与生成速度，让内容无缝分发到各类短视频平台。
* **丰富的语音库与语速调节**：内置多款中文及多语种自然语音，亦可调整语速，让视频旁白更贴合品牌调性。
* **开箱即用的专业模板**：系统提供默认视频模板，无需设计知识即可获得统一美观的视频风格，同时预留自定义模板能力以应对高阶需求。

---

### 💎 积分消耗与结算透明度

* **按场景计费的清晰规则**：快速视频生成采用基础点数加每场景点数的方式计费，不同分辨率对应不同消耗，创作者在确认前即可明确花费。
* **积分扣除与结算实时联动**：任务开始即锁定相应积分，生成成功或失败后立刻完成结算或退款，资金流向实时可见。
* **结算记录新增专项明细**：广告主和运营可以在资金流水或任务详情中查到快速视频生成的专项条目，审计对账更省心。

---

### ⚙️ 任务调度与生成可靠性

* **主动式生成状态跟踪**：平台自动定时检查每个快速视频任务的最新进度，确保完成视频及时回传，失败任务快速反馈。
* **并发控制保障任务不拥堵**：多用户同时使用时，系统合理调度生成资源，避免高峰期卡顿，让每个创作请求平稳运行。
* **超时与异常自动介入**：长时间未完成的任务会被自动标记并释放资源，相关积分同步退回，减少无谓等待。

---

### 🧩 控制台与接口一体化体验

* **创作面板可见全部选项**：在草稿生成视图内，创作者可以直接查看可用声音、模板、分辨率及对应积分消耗，无需跳转即可完成设置。
* **广告主任务流程无缝衔接**：新建图文或视频任务时，快速视频类型已整合进创作入口，一键下发，简化投放操作。
* **开发者友好接口扩展**：相关 API 客户端已同步新增快速视频请求与响应模型，支持外部系统快速集成这一创作能力。

### 🧹 系统稳定与体验优化

* **新版创作模块平滑融入现有架构**：快速视频服务与原有视频、图片生成管线深度整合，保证整体系统行为一致、维护更高效。
