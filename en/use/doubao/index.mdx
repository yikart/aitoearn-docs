This guide shows how to integrate AiToEarn in the Doubao desktop client. After setup, you can upload the AiToEarn skill package and connect AiToEarn's Agent capabilities to Doubao conversations through a custom connector.

<Info>
  The skill entry is only available in the Doubao desktop client (Mac/Windows). The web version and mobile app do not have it. If you do not have an API Key yet, read [Get API Key](/en/use/api-key).
</Info>

## Prerequisites

Before you start, make sure you have:

1. An AiToEarn account and [AiToEarn API Key](/en/use/api-key).
2. The Doubao desktop client (Mac/Windows).
3. The [AiToEarn Doubao skill package](/assets/downloads/aitoearn-doubao-skill-0.0.4.zip).

## Upload the Skill Package

Open the Doubao desktop client, go to **Plugins · Skills · Partners** in the left sidebar, switch to the **Skills** tab, click **+ Add** in the top-right corner, and choose **Upload Skill**.

![Choose Upload Skill in Doubao](/assets/use/doubao/01-upload-skill-entry.png)

Drag [aitoearn-doubao-skill-0.0.4.zip](/assets/downloads/aitoearn-doubao-skill-0.0.4.zip) directly into the upload area, or click **Select File**. Do not unzip it. The archive must contain a `SKILL.md` file with the skill name and description in YAML format.

![Doubao upload skill dialog](/assets/use/doubao/02-upload-skill-dialog.png)

## Create a Custom Connector

On the same page, click **+ Add** in the top-right corner and choose **New Custom Connector**.

![Choose New Custom Connector in Doubao](/assets/use/doubao/03-custom-connector-entry.png)

Fill in the dialog as follows:

![Doubao custom connector dialog](/assets/use/doubao/04-custom-connector-dialog.png)

| Field | Value |
| --- | --- |
| Server name | `AiToEarn` |
| Transport type | `HTTP` |
| Server URL | `https://aitoearn.ai/api/ai/agent/mcp` for international accounts, `https://aitoearn.cn/api/ai/agent/mcp` for China accounts |
| Custom Headers | Add one entry: `X-Api-Key` = your AiToEarn API Key |

The URL must match the site where your API Key was created. Click **Save** when done.

Once saved, the AiToEarn connector appears in the connector list with a toggle. Click the connector name to view all operations (tools) it includes and confirm they match your expectations.

![Connector configured successfully with its operations](/assets/use/doubao/05-connector-success.png)

## Use It

Once configured, select the AiToEarn skill in a Doubao conversation first: click **Skills** below the chat input box and choose `aitoearn` under **Created by me**.

![Select the AiToEarn skill in a Doubao conversation](/assets/use/doubao/06-select-skill.png)

Then describe your need, for example:

> Plan a week of short video content for me, with topics, scripts, and cover images.

Doubao will automatically invoke the AiToEarn skills and connector based on the conversation.

## Troubleshooting

- Connector call failed: make sure the URL matches the site of your API Key, and the Key comes from the [AiToEarn API Key page](/en/use/api-key).
- Cannot find the skill entry: make sure you are using the Doubao desktop client; the web version and mobile app do not have it.
