---
title: "Get API Key"
---

Create an API Key before calling AiToEarn Open Platform APIs.

## Steps

1. Sign in to AiToEarn.
2. Open the settings page.
3. Go to the API Key page.
4. Create a new API Key.
5. Copy and store the key securely.

Use this key in API requests. Most Open Platform APIs use the `X-Api-Key` header.

## Next step

After creating an API Key, continue with [Publishing flow](/en/use/publish-flow) or one of the AI generation tutorials.
