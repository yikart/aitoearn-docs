This guide shows how to use AiToEarn in WorkBuddy. WorkBuddy provides an experts, skills, and connector market where you can use the AiToEarn expert directly and connect the AiToEarn MCP connector for content creation and publishing.

<Info>
  If you do not have an API Key yet, read [Get API Key](/en/use/api-key).
</Info>

## Prerequisites

Before you start, make sure you have:

1. An AiToEarn account and [AiToEarn API Key](/en/use/api-key).
2. WorkBuddy installed and working.

## Use the Expert

Open WorkBuddy, go to the **Experts · Skills · Connectors** page, search for the AiToEarn omnichannel content operations expert, and add it.

![Search for the AiToEarn expert in WorkBuddy](/assets/use/workbuddy/01-search-expert.png)

## Connect AiToEarn MCP

In the chat input box, switch the mode to **Expert**, select the AiToEarn content operations expert, then choose the AiToEarn MCP connector to connect: **AiToEarn MCP (International)** or **AiToEarn MCP (China)**.

![Select the expert and connector in a WorkBuddy conversation](/assets/use/workbuddy/02-use-expert.png)

On first connect, a configuration dialog appears. Enter your AiToEarn API Key matching the connector site (aitoearn.cn Key for the China connector, aitoearn.ai Key for the international connector) and click **Save and Connect**.

![Configure the AiToEarn API Key](/assets/use/workbuddy/03-configure-api-key.png)

Once connected, you can use it directly in the conversation, for example:

> Plan a week of short video content for me, with topics, scripts, and cover images.

You can review and manage the connection status in custom connector settings.

## Troubleshooting

- Connection failed: make sure the API Key comes from the [AiToEarn API Key page](/en/use/api-key) and matches the connector site (China and international Keys are not interchangeable).
- Expert not found: make sure you search for the AiToEarn content operations expert on the **Experts · Skills · Connectors** page.
