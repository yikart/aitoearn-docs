Most endpoints use `X-Api-Key` authentication. Go to the [API key guide](/en/use/api-key) to get one.

## Base URLs

- China site: `https://aitoearn.cn`
- International site: `https://aitoearn.ai`

You can switch servers in the playground panel on each API page and enter the API Key for the selected site.

## Coverage

- AI services: video generation, real-person assets, image generation, and large language models.
- Channel management: accounts, content publishing, platforms, works, account groups, and authorization.
- Asset management: upload signatures and upload confirmation.
