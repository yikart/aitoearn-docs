本文介绍如何在 Trae 中接入 AiToEarn。Trae 通过插件市场管理扩展，你可以在其中配置 AiToEarn 的 MCP Server，也可以上传包含 `SKILL.md` 的技能包，然后在对话中直接调用 AiToEarn 能力。

<Info>
  如果你还没有 API Key，请先阅读 [获取 API Key 教程](/zh/use/api-key)。
</Info>

## 前置条件

开始之前，请确认你已经准备好：

1. AiToEarn 账户和 [AiToEarn API Key](/zh/use/api-key)。
2. 已安装并可正常使用的 Trae。

## 配置 MCP

打开 Trae 的插件市场，进入「管理」页，切换到 MCP 标签，点击「添加」，选择手动配置。

![在 Trae 插件市场中手动配置 MCP](/assets/use/trae/01-configure-mcp.png)

在输入框中粘贴 AiToEarn MCP Server 的配置 JSON（配置前请确认来源可信，甄别风险）。`url` 必须和 API Key 所属站点一致，国内站填 `https://aitoearn.cn/api/ai/agent/mcp`，国际站填 `https://aitoearn.ai/api/ai/agent/mcp`：

```json
{
  "mcpServers": {
    "aitoearn": {
      "url": "https://aitoearn.cn/api/ai/agent/mcp",
      "headers": {
        "X-Api-Key": "你的 AiToEarn API Key"
      }
    }
  }
}
```

确认后保存，返回 MCP 列表确认 AiToEarn 服务已启用（开关为打开状态）。如需确认可用模型名称，请查看 [对话模型列表](/api-reference/get-api-ai-models-chat)。

<Info>
  如果你已经上传了下方的 AiToEarn 技能包，包内的 `scripts/aitoearn-mcp-setup.mjs` 可以自动完成以上注册和验证：在终端运行 `node scripts/aitoearn-mcp-setup.mjs <API_KEY> cn`（国内站）或 `node scripts/aitoearn-mcp-setup.mjs <API_KEY> ai`（国际站）。
</Info>

## 上传技能包

在插件市场「管理」页的「技能」标签下，点击「上传技能」，拖放或选择包含根级 `SKILL.md` 文件的 `.zip` 或 `.skill` 文件。

![在 Trae 中上传技能包](/assets/use/trae/02-upload-skill.png)

`SKILL.md` 中以 YAML 格式编写技能名称和描述，上传后 Trae 会根据描述自动识别技能用途。

你可以直接下载我们准备好的 AiToEarn Trae 技能包：

[下载 AiToEarn Trae 技能包](/assets/downloads/aitoearn-trae-0.0.4.zip)

## 调用技能

在对话输入框中点击左下角的 `+`，选择「技能」，在搜索框中输入关键词即可搜索已上传的技能。

![在对话中搜索并调用技能](/assets/use/trae/03-search-skill.png)

选中技能后发送消息，Trae 会在当前对话中调用该技能。

## 常见问题

- MCP 连接失败：确认服务地址正确，API Key 来自 [AiToEarn API Key 页面](/zh/use/api-key)，且与站点一致。
- 技能未被识别：确认压缩包根目录包含 `SKILL.md`，且其中包含合法的 YAML 名称和描述。
