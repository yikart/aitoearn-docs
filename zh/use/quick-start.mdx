## 接入目标

最小链路如下：

```text
准备 API Key -> 读取可用能力 -> 提交 AI 生成任务 -> 创建发布 Flow -> 查询发布记录
```

跑通之后，再按业务需要扩展素材上传、多平台发布、多账号发布、定时发布、失败重试和作品数据追踪。

<Tip>
  不要一开始就把全部接口都接完。先跑通一条真实链路，再围绕业务场景增量建设。
</Tip>

## 第一步：准备 API Key

所有开放平台接口都通过 `X-Api-Key` 鉴权。请在服务端保存 API Key，不要放到浏览器、移动端包或公开仓库中。

<Steps>
  <Step title="打开控制台">
    进入 [AiToEarn 控制台](https://aitoearn.cn/)。
  </Step>
  <Step title="进入设置">
    点击左下角头像，进入设置页面。
  </Step>
  <Step title="打开 API key">
    在左侧侧边栏选择 `API key`。
  </Step>
  <Step title="创建并保存 key">
    点击创建，复制并保存新 key。
  </Step>
</Steps>

<Warning>
  API Key 只应该保存在服务端环境变量、密钥管理服务或后端配置中。不要写入前端代码、客户端包、截图、公开文档或 Git 仓库。
</Warning>

## 第二步：读取可用能力

在提交生成或发布任务前，建议先读取模型、平台和账号信息。

<CardGroup cols={3}>
  <Card title="AI 生成" icon="sparkles">
    先查询模型列表和参数范围。
  </Card>
  <Card title="渠道发布" icon="send">
    先查询平台元数据、账号列表和账号授权状态。
  </Card>
  <Card title="平台参数" icon="file-sliders">
    如平台存在动态字段，先查询动态发布选项。
  </Card>
</CardGroup>

这样你的系统可以根据接口返回值渲染表单、校验参数，并减少调用失败。

<Info>
  不要把平台限制、模型参数和动态选项写死在代码里。优先使用接口返回的元数据做表单渲染和参数校验。
</Info>

## 第三步：提交一个 AI 生成任务

下面示例提交一个视频生成任务。

<CodeGroup>

```bash Windows
curl -k --location "https://aitoearn.cn/api/ai/video/generations" ^
  --header "X-Api-Key: <your-api-key>" ^
  --header "Content-Type: application/json" ^
  --data "{\"model\": \"seedance-2-fast-beta\", \"prompt\": \"一只橘猫在雨后的街角慢慢走过\", \"resolution\": \"720p\", \"ratio\": \"16:9\", \"duration\": 4}"
```

```bash macOS / Linux
curl -k --location "https://aitoearn.cn/api/ai/video/generations" \
  --header "X-Api-Key: <your-api-key>" \
  --header "Content-Type: application/json" \
  --data '{
    "model": "seedance-2-fast-beta",
    "prompt": "一只橘猫在雨后的街角慢慢走过",
    "resolution": "720p",
    "ratio": "16:9",
    "duration": 4
  }'
```

</CodeGroup>

视频生成的必填字段是 `model` 和 `prompt`。`resolution`、`ratio`、`duration` 以及参考图片、视频、音频等字段按模型能力选择传入即可。

视频生成是异步任务。接口会先返回 `taskId`，随后使用 `taskId` 查询状态和结果。

<CodeGroup>

```bash Windows
curl -k --location "https://aitoearn.cn/api/ai/video/generations/{taskId}" ^
  --header "X-Api-Key: <your-api-key>"
```

```bash macOS / Linux
curl -k --location "https://aitoearn.cn/api/ai/video/generations/{taskId}" \
  --header "X-Api-Key: <your-api-key>"
```

</CodeGroup>

异步图像生成和编辑接口会返回 `logId`，对应使用图像任务查询接口获取状态和结果。

完成以上步骤后，你就已经拥有一条最小可用链路：能准备素材、授权账号、提交发布并查询结果。后续扩展 AI 生成、多平台、多账号、定时发布、失败重试和运营数据时，都可以在这条链路上增量建设。
