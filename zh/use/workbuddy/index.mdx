本文介绍如何在 WorkBuddy 中使用 AiToEarn。WorkBuddy 提供「专家 · 技能 · 连接器」市场，你可以直接使用 AiToEarn 专家，并连接 AiToEarn MCP 连接器来使用内容生成与发布能力。

<Info>
  如果你还没有 API Key，请先阅读 [获取 API Key 教程](/zh/use/api-key)。
</Info>

## 前置条件

开始之前，请确认你已经准备好：

1. AiToEarn 账户和 [AiToEarn API Key](/zh/use/api-key)。
2. 已安装并可正常使用的 WorkBuddy。

## 使用专家

打开 WorkBuddy，进入「专家 · 技能 · 连接器」页，搜索「全域内容运营专家」，找到 AiToEarn 的专家卡片并添加使用。

![在 WorkBuddy 中搜索 AiToEarn 专家](/assets/use/workbuddy/01-search-expert.png)

## 连接 AiToEarn MCP

在对话输入框中，将模式切换为「专家」，选择「全域内容运营专家」，然后选择要连接的 AiToEarn MCP 连接器：「AiToEarn MCP（国际站）」或「AiToEarn MCP（中国站）」。

![在 WorkBuddy 对话中选择专家和连接器](/assets/use/workbuddy/02-use-expert.png)

首次连接时会弹出配置窗口，按提示填入你的 AiToEarn API Key（连接器与站点对应：中国站填 aitoearn.cn 的 Key，国际站填 aitoearn.ai 的 Key），点击「保存并连接」。

![配置 AiToEarn API Key](/assets/use/workbuddy/03-configure-api-key.png)

连接成功后即可在对话中直接使用，例如：

> 帮我排一周的短视频内容，直接出选题、脚本和封面图

连接状态可以在自定义连接器管理中查看和调整。

## 常见问题

- 连接失败：确认 API Key 来自 [AiToEarn API Key 页面](/zh/use/api-key)，且与所选连接器站点一致（中国站 Key 不能用于国际站，反之亦然）。
- 找不到专家：确认在「专家 · 技能 · 连接器」页搜索「全域内容运营专家」。
