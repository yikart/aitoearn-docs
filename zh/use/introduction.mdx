AiToEarn Open Platform 提供开放 API，帮助你在自己的系统中接入账号授权、素材上传和多平台发布能力。

第一次接入建议先创建 API KEY，再按发布流程跑通一次完整发布。如果你只需要生成能力，也可以直接阅读对应模型教程。
