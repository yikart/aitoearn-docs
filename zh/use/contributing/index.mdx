很高兴你有兴趣为 AiToEarn 做出贡献——这太棒了！我们致力于构建最佳的 AI 赚钱平台，来自社区的任何帮助都非常宝贵。

本指南旨在让你熟悉代码库以及我们与贡献者的合作方式，以便你可以快速进入正题。它是一个持续完善的过程，如果有时滞后于实际项目，欢迎提出改进反馈。

## 在开始之前

正在寻找可以解决的问题？浏览我们的 [issues](https://github.com/yikart/AiToEarn/issues) 并挑选一个开始吧！

<AccordionGroup>
  <Accordion title="友好的第一次开始" icon="handshake">
    标题包含 **【good first】** 的 issues，是我们为新的贡献者准备的。如果想加入我们的团队，请提交关联该 issue 的 PR。

    别忘了在 PR 描述中链接现有的 issue。
  </Accordion>

  <Accordion title="错误报告（Bug Reports）" icon="bug">
    提交错误报告时，请务必包含以下信息：

    - 清晰且描述性的标题
    - 错误的详细描述，包括任何错误消息
    - 复现错误的步骤
    - 预期行为
    - **日志**（如果有），对于后端问题，这非常重要
    - 截图或视频（如果适用）

    我们的优先级排序方式：

    | 问题类型 | 优先级 |
    | --- | --- |
    | 核心功能错误（无法登录、应用无法工作、安全漏洞） | 严重（Critical） |
    | 非严重错误、性能提升 | 中等优先级 |
    | 小修补（拼写错误、UI 令人困惑但可工作） | 低优先级 |
  </Accordion>

  <Accordion title="功能请求（Feature Requests）" icon="lightbulb">
    提交功能请求时，请务必包含以下信息：

    - 清晰且描述性的标题
    - 功能的详细描述
    - 功能的使用场景
    - 关于功能请求的任何其他背景信息或截图

    我们的优先级排序方式：

    | 功能类型 | 优先级 |
    | --- | --- |
    | 团队成员标记为高优先级的功能 | 高优先级 |
    | 社区反馈中受欢迎的功能请求 | 中等优先级 |
    | 非核心功能和小幅增强 | 低优先级 |
    | 有价值但不紧急 | 未来特性 |
  </Accordion>
</AccordionGroup>

## 开发环境设置

1. Fork 项目到你的 GitHub 账号。
2. 创建特性分支：

   ```bash
   git checkout -b feature/your-feature-name
   ```

3. 提交你的更改：

   ```bash
   git add .
   git commit -m "feat: add new feature"
   ```

4. 推送到你的 Fork 仓库：

   ```bash
   git push origin feature/your-feature-name
   ```

5. 在 GitHub 上创建 Pull Request。

## 提交你的 PR

<Steps>
  <Step title="Fork 本仓库">
    在 GitHub 上 Fork [AiToEarn](https://github.com/yikart/AiToEarn) 到你的账号。
  </Step>

  <Step title="先创建 issue 讨论">
    在起草 PR 之前，请创建一个 issue 来讨论你想要进行的更改。
  </Step>

  <Step title="创建分支并修改">
    为你的更改创建一个新分支，并相应地为你的更改添加测试。
  </Step>

  <Step title="确保测试通过">
    确保你的代码通过现有的测试。
  </Step>

  <Step title="提交 PR 并链接 issue">
    请在 PR 描述中链接该 issue，例如 `fixes #<issue_number>`。
  </Step>

  <Step title="等待合并">
    等待维护者 review 并合并。
  </Step>
</Steps>
