AiToEarn Open Platform 是面向开发者的内容生成与多平台发布 API。你可以通过一套清晰的接口，把 AI 视频、AI 图像、模型调用、素材上传、账号授权、发布 Flow 和作品追踪接入到自己的产品中，搭建从“生成内容”到“发布到全平台”的自动化工作流。

如果你正在开发内容中台、营销自动化工具、创作者后台、品牌矩阵发布系统或第三方 SaaS 集成，AiToEarn Open Platform 可以作为底层的 AI 内容生产和渠道发布能力。

## 一句话理解

用 API 生成内容，用 Flow 编排发布，用记录追踪结果。

开放平台不只是单个生成接口，也不只是渠道发布接口。它把内容生产、素材管理、平台差异、账号授权和发布状态连接成一条可编排的链路：

```text
AI 生成 -> 素材上传 -> 账号授权 -> 创建发布 Flow -> 查询发布记录 -> 获取作品数据
```

你可以从其中任意一个环节开始接入，再逐步扩展到完整工作流。

## 为什么容易接入

AiToEarn Open Platform 通过统一鉴权、元数据查询、异步状态追踪和标准化发布编排降低集成复杂度。开发者可以先了解模型、平台和账号能力，再按稳定链路完成内容生成、素材上传、渠道发布和结果追踪，将平台差异转化为可查询、可配置、可追踪的集成能力。

| 设计 | 带来的好处 |
| --- | --- |
| 统一鉴权 | 所有开放接口通过 `X-Api-Key` 调用，服务端配置一次即可开始接入。 |
| 先查后用 | 模型、平台、账号、动态发布选项都可通过接口查询，减少手写枚举和平台规则。 |
| 渐进式流程 | 可以先跑通一个 AI 生成任务，或先跑通一个单平台发布 Flow，再逐步扩展。 |
| 异步可追踪 | 生成和发布任务会返回 ID，后续通过查询接口获取状态、结果和失败原因。 |
| 平台差异可控 | 通用内容放在 `content`，平台专属参数放在 `option` 和 `overrides`，结构清楚。 |
| 结果可排查 | 发布记录、作品链接、状态信息和错误信息可用于构建稳定的监控与重试逻辑。 |

## 你可以用它做什么

### 生成 AI 内容

调用统一的 AI 服务接口生成视频、图片或调用大模型能力。

<CardGroup cols={2}>
  <Card title="视频生成" icon="video">
    支持 Seedance 系列视频生成模型。提交异步视频生成任务，可使用文本、图片、视频、音频等参考素材。
  </Card>
  <Card title="图像生成" icon="image">
    支持 GPT-image-2 等图像模型，并区分图像生成与图像编辑接口。
  </Card>
  <Card title="模型中转" icon="messages-square">
    兼容 OpenAI Chat Completions、Anthropic Messages、Gemini GenerateContent / StreamGenerateContent，以及 OpenAI 图像生成/编辑接口。
  </Card>
  <Card title="模型参数查询" icon="file-sliders">
    在提交任务前读取模型支持的分辨率、比例、时长、价格和输入限制。
  </Card>
</CardGroup>

### 发布到多个平台

通过发布 Flow 将同一份内容分发到多个渠道账号，并为不同平台设置差异化参数。

- 查询平台元数据和平台能力。
- 查询账号列表、账号详情和授权状态。
- 读取动态发布选项，例如分类、分区、Board、隐私状态等。
- 创建发布 Flow，一次请求生成多个单平台发布任务。
- 查询 Flow 详情和发布记录。
- 获取作品链接、发布状态和需要用户操作的信息。

<Info>
  目前开放平台文档展示了 YouTube、抖音、TikTok、小红书、Instagram、Facebook、Twitter（X）、哔哩哔哩、快手、微信视频号、微信公众号、Threads、Pinterest、LinkedIn 等 14+ 平台能力。
</Info>

### 管理素材和资源

通过上传签名接口将外部文件安全直传到对象存储，再把上传后的资源 URL 用于 AI 生成或内容发布。

- 上传视频、图片、封面、音频等发布素材。
- 通过 `filename`、`type`、`size` 获取上传签名，再在直传完成后确认资源。
- 将 AI 生成结果保存为素材。
- 将素材写入发布 Flow 的 `content.media`、`cover` 或平台 `overrides`。

### 查询账号、作品和互动数据

开放平台也提供渠道管理能力，适合构建运营后台或自动化监控。

- 账号管理和账号分组。
- 作品列表、作品详情和作品链接状态。
- 互动函数调用。
- 平台能力、动态选项和发布限制查询。

## 核心概念

<AccordionGroup>
  <Accordion title="API Key">
    开放平台的接口凭证。所有请求都需要携带 `X-Api-Key`。建议只在服务端使用。
  </Accordion>
  <Accordion title="Model">
    AI 能力的模型 ID。不同模型支持的输入素材、分辨率、比例、时长和价格可能不同。提交任务前建议先读取模型参数接口。
  </Accordion>
  <Accordion title="Task">
    异步任务。视频生成会返回 `taskId`，异步图像生成/编辑会返回 `logId`，再通过查询接口获取状态和结果。
  </Accordion>
  <Accordion title="Asset">
    平台中的资源或素材。你可以通过上传签名接口上传文件，再将资源 URL 用于 AI 生成或发布 Flow。
  </Accordion>
  <Accordion title="Account">
    已授权的平台账号。发布内容前需要先完成平台授权，并在发布任务中指定 `accountId`。
  </Accordion>
  <Accordion title="Platform Metadata">
    平台元数据描述平台能力、字段限制和动态发布选项。它可以帮助你的系统按平台生成表单和校验规则。
  </Accordion>
  <Accordion title="Publish Flow">
    一次发布编排。一个 Flow 可以包含多个平台任务，每个平台任务可以有自己的账号、平台选项和覆盖内容。
  </Accordion>
  <Accordion title="Publish Record">
    单个平台发布任务的记录。你可以通过它查询发布状态、作品链接、失败原因或用户操作信息。
  </Accordion>
</AccordionGroup>

## 友好接入

### 渐进式接入

你不需要一次接入所有模块。可以先用 AI 生成内容，也可以先接入发布 Flow；当业务复杂度提升后，再逐步增加素材上传、平台动态选项、作品追踪和互动数据。

### 元数据驱动

不同平台的字段、限制和发布选项并不完全相同。开放平台将这些差异通过平台元数据和动态选项暴露出来，让你的产品可以根据接口返回值自动适配。

<Tip>
  这意味着你的系统不必维护大量平台规则表。比如分类、分区、Board、隐私状态等动态选项，都可以在发布前按账号和平台实时获取。
</Tip>

### 异步友好

生成和发布通常不是瞬时完成的。开放平台通过任务 ID、Flow ID 和发布记录 ID 暴露状态流转，让你可以构建稳定的轮询、重试和错误处理逻辑。

### 保留平台差异

开放平台提供统一的接入模型，但不会抹平平台差异。通用内容放在 `content` 中，平台专属参数放在 `option` 和 `overrides` 中，既保持统一，又保留灵活性。

### 可排查

AiToEarn 的任务、Flow 和发布记录都围绕“状态、结果、错误原因、作品链接”组织，便于你在自己的系统中建设日志、告警和人工处理入口。
