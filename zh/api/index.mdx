大多数接口使用 `X-Api-Key` 鉴权，点击前往 [API key 获取教程](/zh/use/api-key)。

## 调试地址

- 中国站：`https://aitoearn.cn`
- 国际站：`https://aitoearn.ai`

在接口页右侧的调试面板中可以切换 server，并填写对应的 API Key。

## 覆盖范围

- AI 服务：视频生成、图像生成、大语言模型。
- 渠道管理：账号、内容发布、平台、作品、账号分组、授权。
- 资源管理：上传签名与上传确认。
