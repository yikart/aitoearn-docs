本指南用于帮助创作者保持 Facebook 账号稳定，确定内容方向并持续优化运营效果。

## 项目介绍

在平台上挑选要推广的短剧，找到想要推广的视频进行下载，结合短剧下载页面右侧的【推广链接】进行创作，发布视频后引导用户下载对应的播放App，进行观看。

## 地区与IP的选择

<Note>
  外国人演的外国剧叫做本土剧，中国人演的中国剧+外语配音叫做国产翻译剧。
</Note>

账号环境、短剧语言和目标受众应保持一致：

- 短剧语言决定账号地区： 英语短剧分为本土短剧和国产翻译剧。
- 欧美地区（高付费能力）：IP选美国/欧洲 ➜ 推广本土短剧。
- 日韩东南亚地区（用户基数大）：IP根据做的语种和地区选择 ➜ 推荐日韩、泰语、印尼语等，本土剧翻译剧均可。
- 例如：选择美国作为账号地区IP，就主发本土剧，不要发泰剧或其他语言的短剧。

如需调整账号地区，请先暂停账号操作，完成设备语言、时区和网络环境调整后再登录。避免短时间内反复切换或频繁登录、退出。

## IP更换规则

更换规则：如果你要换别的语言的短剧，可以换地区、换IP，但切记不要频繁操作！

以手机为例，更换步骤如下：
1. 开启飞行模式
2. 退出账号
3. 等待数小时后切换IP
4. 关闭飞行模式并重新登录

## 账号异常处理

- 常见问题：注册账号就被封号；
- 一般原因：大概率账号被风控，被风控一般是因为网络不行或者伪装度不够被检测到；
- 解决方案：更换干净的网络，手机设备必须重新刷机后再尝试注册。

### 视频创作建议

<Warning>
  新号最开始发的视频控制在3分钟左右比较好，视频太长会影响完播率，进而影响推流效果。
</Warning>

  以下是几种常见的剪辑形式，中期还可以通过对标优质账号的内容[剪辑要求](#剪辑要求)学习更多的内容剪辑玩法：

| 形式 | 特点 |
| --- | --- |
| 配乐卡点混剪 | 节奏鲜明，适合新号 |
| 原片片段、标题与配乐 | 操作简单，适合快速制作 |
| 解说配音与原片 | 便于说明剧情和引导用户 |

<Danger>
  **版权风险**

  在增加解说字幕和背景音乐时，需注意音乐和字体版权问题。可以使用无版税的音乐和字体，或者确保你已经获得了其合法使用权。
</Danger>

### 剪辑要求

视频黄金时长为3-5秒， 前3秒必含以下高能元素（至少1项）

| 情绪标签 | 剧情关键词 |
| --- | --- |
| 冲突爆发 | 强强对峙 \| 财富突降 \| 突发反转 |
| 感官刺激 | 亲密吻戏 \| 惊悚悬疑 \| 便装穿越 |
| 身份逆转 | 扮猪吃虎 \| 霸总强宠 \| 萌娃变故 |
| 情感共鸣 | 弱势委屈 \| 不公遭遇 \| 悲情失忆 |

注意事项
- 前5秒内避免 全景慢镜头
- 拒绝 线性叙事（必须 倒叙/插叙）
- 禁止使用 纯文字解说（需画面直给）
- 控制单条时长：避免将原片整合为长视频（如1-5集合并），否则会显著降低 完播率 与 平台推流。
- 拒绝直接搬运：需对原片进行二次剪辑，删除冗余内容，提炼核心看点。
