部分短剧任务要求先完成账号报备。请使用与报备资料一致的账号发布内容；未按任务要求报备，可能影响内容审核、任务验证或结算。

<Tip>
  如果还不清楚短剧任务的完整流程，请先查看 [短剧任务指南](/zh/help/short-drama)。
</Tip>

## 先确认是否需要报备

进入短剧任务详情页，先查看账号报备状态和前置条件。不同剧集、发布平台和任务的要求可能不同，始终以当前任务页面为准：

- 页面提示需要报备时，先提交账号资料；
- 页面提示需要等待审核、加白或完成其他条件时，状态满足后再剪辑或发布；
- 页面明确显示提交资料后即可继续时，按页面指引操作；
- 不要沿用其他剧集或过去任务的报备规则。

<Warning>
  审核期间不要修改已提交账号的昵称、账号 ID 或主页链接。报备通过后，也不要更换其他账号完成同一任务。
</Warning>

## 报备前准备

准备计划用于发布短剧内容的社媒账号，并确认账号可以正常登录和发布。每个账号通常需要提供：

- 账号昵称或频道名称；
- 账号 ID；
- 账号主页或频道链接。

<Note>
  账号 ID 不等于昵称。请从账号主页或账号设置中复制，避免手动输入错误。Facebook、TikTok 和 YouTube 的资料获取方式见下文。
</Note>

如需在海外平台中完成授权或管理多个账号，请先为每个账号准备独立且稳定的浏览器环境，详见 [云工作区图文教程](/zh/help/cloud-workspace)。

## 报备流程

1. 进入短剧任务详情页，确认当前任务是否需要账号报备。
2. 从页面顶部进入 **账号报备**。
3. 选择社媒平台，填写账号昵称、账号 ID 和主页链接。
4. 提交资料后，在账号报备页或任务详情页查看状态。
5. 仅使用任务允许且与报备资料一致的账号继续剪辑、发布和提交。

部分任务提交资料后可以继续，部分任务需要等待审核通过；如有额外要求，以任务详情页显示的状态和说明为准。

## 同一平台报备多个账号

点击 **新增账号**，依次填写并提交其他账号的信息。每个账号都应填写各自的昵称、账号 ID 和主页链接，不要复制其他账号的资料。

### Facebook

<Warning>
  不要提交包含 `/share/` 的 Facebook 分享链接，例如 `https://www.facebook.com/share/XXX`。请打开分享链接，在页面跳转后复制最终的主页链接。
</Warning>

请填写任务页面要求、并实际用于发布任务内容的 Facebook 对象资料；通常为公共主页。若不确定应填写个人账号还是公共主页，请先以任务页面的字段说明为准，不要使用个人分享链接代替主页链接。

可提交的主页链接通常类似：

- `https://www.facebook.com/profile.php?id=xxxxx`
- `https://www.facebook.com/username`
- `https://m.facebook.com/123456789`

### Instagram

Instagram 的账号昵称和账号 ID 均填写用户名，主页链接从个人主页复制。

## 审核未通过怎么办？

根据失败原因逐项检查，修改后重新提交：

- 账号 ID 是否填写正确；
- 主页链接能否正常打开；
- 昵称、ID 和主页链接是否属于同一账号；
- 账号是否满足任务页面显示的平台或账号条件；
- 实际要发布的账号是否与报备账号一致。

人工审核需要一定时间，请预留准备时间。若任务页提示的要求与本页不同，以任务页为准。

## 注意事项

- 只报备计划用于发布任务内容的账号；
- 要求报备通过的任务，在通过前不要发布相关内容；
- 使用报备通过的账号完成任务，不要在中途替换账号；
- 账号、内容、版权和平台审核由第三方平台独立判断；
- 任务规则可能更新，请以任务详情页的最新状态和说明为准。
