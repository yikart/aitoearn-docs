部分短剧任务要求先完成账号报备。请使用报备通过的账号发布，否则内容可能无法通过审核或影响结算。

## 报备规则

<Info>
  无需手动选择剧场。提交需要推广的社媒账号信息后，系统会自动申请对应剧场的报备。
</Info>

报备需填写账号的**频道昵称、频道 ID 和主页链接**。KalosTV、HoneyReels 由系统自动报备，其他需要审核的剧场通常在两个工作日左右完成。

### 不需要报备

- FlareFlow
- SnackShort
- GoodShort
- TouchShort
- DreameShort
- Pancake

### 必须报备

- KalosTV
- DramaBox
- ShortMax
- FlickReels
- ReelShort（Boost）
- HoneyReels
- MoboReels
- Playlet
- StarShort
- Sereal+

未按要求报备，发布的视频可能被封禁或下架。

### 特殊要求

- **Sereal+、Playlet、FlickReels**：提交账号信息后即可发布，无需等待报备成功。
- **ReelShort（Boost）**：只需报备 TikTok 账号。
- **DramaBox**：社媒账号粉丝数需达到 100 以上。
- **MoboReels**：发布前需填写 [MoboReels 账号报备问卷](https://cvbadml3pe5.feishu.cn/share/base/form/shrcnNRd8OhBoZs4N3FOYzJzF7b)，问卷中资源渠道填写北斗。
- **KalosTV**：发布剧单中版权方为“番茄”的短剧前，需[查询加白结果](https://web.wps.cn/etapps/query/q/NZbAuRnP)。未查询到加白成功时请勿剪辑发布，以免触发版权下架。等待期间可选择版权方为“青榕”的短剧或其他剧场任务。

账号信息填写错误会被退回。请修改为正确的信息后重新提交。

## 报备前准备

准备需要发布短剧内容的社媒账号，并确认账号可以正常登录和发布。

每个账号需提供：

- 账号昵称或频道名称
- 账号 ID
- 账号主页链接

<Note>
  账号 ID 不是昵称。请从账号主页或账号设置中复制，避免手动输入错误。
</Note>

## 报备流程

1. 进入短剧任务页面，查看是否需要账号报备。
2. 从头部导航中打开账号报备入口，选择需要发布内容的社媒平台。
3. 选择社媒平台填写账号昵称、账号 ID 和主页链接。
4. 等待审核，通过后使用对应账号发布内容。

部分任务提交账号信息后即可继续，部分任务需等待审核通过。具体以任务页面提示为准。

## 如何获取账号信息

### TikTok

- **账号昵称**：个人主页显示的名称
- **账号 ID**：个人主页中的 `@用户名`
- **主页链接**：打开个人主页后复制链接

### Facebook

- **频道名称**：公共主页名称
- **频道 ID**：公共主页的 Page ID
- **主页链接**：打开公共主页后复制链接

### YouTube

- **频道名称**：频道主页显示的名称
- **频道 ID**：YouTube 设置或频道高级设置中的频道 ID
- **主页链接**：打开频道主页后复制链接

### Instagram

- **账号昵称**：个人主页显示的名称
- **账号 ID**：个人主页中的用户名
- **主页链接**：打开个人主页后复制链接

## 审核未通过怎么办

根据失败原因检查以下内容，修改后重新提交：

- 账号 ID 是否填写正确
- 主页链接能否正常打开
- 昵称、ID 和主页链接是否属于同一账号
- 账号平台及粉丝量是否符合任务要求
- 提交的账号是否与实际发布账号一致

审核通常需要一定时间，请提前报备。审核期间不要修改账号昵称、ID 或主页链接。

## 注意事项

- KalosTV、Shortmax、HoneyReels因为是系统直接报备所以能够实时返回账号是否报备成功，DramaBox、FlickReels、Boost报备是人工报备时间比较慢，报备成功后也同样会在后台显示是否报备成功。
- DramaBox报备必须填写频道ID/账号ID这个字段，不然无法报备，Youtube平台和FaceBook平台直接在主页显示，报备TikTok平台填写频道ID/账号ID是指的账号UID。
- 只需报备计划用于发布任务内容的账号。
- 不同短剧任务的报备要求可能不同，以任务页面为准。
- 未通过报备前，不要提前发布要求报备的内容。
- 报备通过后，请勿更换账号完成任务。
