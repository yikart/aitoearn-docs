## 项目介绍

本指南用于帮助创作者搭建 TikTok 短剧账号，保持账号稳定，并持续提升内容转化效果。

| 类型 | 适用条件 | 收益触发条件 |
| --- | --- | --- |
| 链接推广 | 粉丝 ≥1000 | 用户通过主页挂载的推广链接下载 App，搜索推广口令或剧名，观看并充值后触发收益 |
| 口令推广 | 粉丝 &lt;1000 | 用户通过视频标题或评论区推广口令下载 App，搜索推广口令，观看并充值后触发收益 |

<Note>
  口令推广不限制粉丝数；粉丝超过 1000 后，仍建议同时使用口令推广和主页链接，提升转化路径覆盖。
</Note>

## 地区与 IP 选择

账号地区、内容语种和目标受众需保持一致。

- 欧美地区：适合英语短剧、本土剧和高付费题材。
- 东南亚地区：适合本地语种短剧、翻译剧和高频更新内容。
- 单个账号建议只做一个语种和一个内容方向，避免影响系统推荐。

<Warning>
  不要频繁切换 IP、设备语言和账号地区。切换前先暂停账号操作，确认环境一致后再登录。
</Warning>

## IP 更换规则

更换规则：如果你要换别的语言的短剧，可以换地区、换IP，但切记不要频繁操作！

以手机为例，更换步骤如下：

1. 开启飞行模式
2. 退出账号
3. 等待数小时后切换IP
4. 关闭飞行模式并重新登录

## 账号注册

### 注册前准备

**物料准备：**

- 邮箱或手机号：使用未注册过 TikTok 的邮箱推荐outlook邮箱。
- 网络：使用干净稳定的目标地区 IP。
- 设备：优先使用独立手机或云手机(如[duoplus](https://www.duoplus.cn/))。
- 素材：提前准备短剧片段、标题、简介、推广链接和标签。

**账号储备：**

建议提前准备多个账号，避免单个账号异常影响内容测试。

**账号注册要求：**

- 严禁冒用短剧版权方官方名义注册账号。
- 禁止使用剧场官方标识（LOGO）作为头像。
- 严禁直接搬运官方素材，或简单添加水印、滤镜后再次发布。
- 禁止发布官方授权集数之外的集数。免费集后的付费集视频素材必须剪辑二创，不能拼接直接发布。

<Danger>
  违反以上规则，可能导致举报受理、账号封禁，且相关口令或链接产生的收益无法结算。
</Danger>

### 账号注册流程

#### Outlook 邮箱注册（推荐）

优先使用 Outlook 邮箱注册 TikTok 账号。

<Tip>
  除了自己注册，也可以直接购买成品邮箱，适合批量准备账号。
</Tip>

<Note>
  新号前期不要频繁改名、换头像、切换设备或批量关注，避免触发风控。
</Note>

### 账号养号与运营

**养号操作流程：**

- 持续 **刷视频半天**
- 间歇性 **点赞**（每 10 条点 1-2 次）
- 随机 **评论**（简短自然，如 Nice!）
- 选择性 **关注**（3-5 个相关领域账号）

**合格账号检查标准：**

- 算法适配：推荐视频与你的兴趣匹配。
- 关注可见性：你关注的账号会实时显示在关注列表；其他账号关注你时，会出现在被关注列表。
- 双向验证：用其他账号搜索并确认新号可以被检索。

**通过验证后操作：**

- 绑定支付方式或邮箱。
- 开始发布内容时，前 3 条视频保持日更。

**测试流程：**

- 发布测试视频：上传实拍原创内容，建议时长 ≤15 秒。
- 数据观察期：等待 24 小时后查看播放量。

**账号等级判定：**

| 播放量区间 | 状态标签 | 操作指令 |
| --- | --- | --- |
| ≤300 | 无效号 | 立即弃用，刷机后重新注册 |
| 300-1000 | 合格号 | 保留并优化内容 |
| ≥1000 | 天选号 | 绑定矩阵资源，重点运营 |

<Tip>
  **进阶建议：**

  天选号首发视频需保持日更节奏。

  合格号可通过投流加热突破流量层级。
</Tip>

**注意事项：**

- 批量 0 播放预警：若多个账号均无流量，需检测代理 IP 纯净度和设备指纹伪装。
- 测试内容规范：避免使用搬运素材，视频画质建议 ≥1080p。
- 黄金操作窗口：筛选完成后 48 小时内完善账号资料，如头像、简介和垂直标签。

<Note>

  此时账号以涨粉到 1000 为目的，可在文案中引导用户关注你。如果是做口令推广，可引导用户查看视频里的口令。

**主页挂载链接：**

操作路径：打开 TikTok → `Profile` → `Edit profile`

- 修改头像：`Change photo`
- 修改账号名称：`Name`
- 修改简介文案：`Bio`
- 修改链接：`Website`

**推广链接规则：**

- 不同剧场的推广链接不同；同个剧场下不同短剧的推广链接相同，同个剧场只需放一次推广链接。
- 发布多个剧场的短剧时，可使用[链接树](https://linktr.ee/)进行推广。

## 账号异常处理

| 问题现象 | 解决方案 |
| --- | --- |
| 点赞/关注无反馈 | 继续静置养号 1-2 天 |
| 关注列表持续为空 | 更换 IP 地址后重试 |
| 养号超 3 天仍无法互动 | 放弃此号，重新注册 |

### 视频创作建议

<Warning>
  TikTok视频时长建议2-5分钟。新号最开始发的视频控制在3分钟左右比较好，视频太长会影响完播率，进而影响推流效果。
</Warning>

以下是几种常见剪辑形式，中期可通过对标优质账号学习更多剪辑玩法：

| 形式 | 特点 |
| --- | --- |
| 配乐卡点混剪 | 节奏鲜明，适合新号 |
| 原片片段、标题与配乐 | 操作简单，适合快速制作 |
| 解说配音与原片 | 便于说明剧情和引导用户 |

<Danger>
  **版权风险**

  在增加解说字幕和背景音乐时，需注意音乐和字体版权问题。可以使用免版税的音乐和字体，或者确保你已经获得了其合法使用权。- 如用到背景音乐，务必用TikTok或CapCut（剪映国际版）的音乐库。
</Danger>

### 剪辑要求

视频开头 3-5 秒决定用户是否停留，建议至少包含 1 类高能元素：

| 情绪标签 | 剧情关键词 |
| --- | --- |
| 冲突爆发 | 强强对峙 \| 财富突降 \| 突发反转 |
| 感官刺激 | 亲密吻戏 \| 惊悚悬疑 \| 便装穿越 |
| 身份逆转 | 扮猪吃虎 \| 霸总强宠 \| 萌娃变故 |
| 情感共鸣 | 弱势委屈 \| 不公遭遇 \| 悲情失忆 |

**注意事项：**

- 前 5 秒避免全景慢镜头。
- 避免线性叙事，优先使用倒叙或插叙。
- 不建议只用纯文字解说，需让画面直接给出看点。
- 避免将多集原片直接合并成长视频，否则会影响完播率和平台推流。
- 不要直接搬运原片，需二次剪辑、删减冗余内容并提炼核心看点。
- 封面风格尽量统一，让用户能快速识别同一剧集或同一账号内容。
- 封面可突出推广链接、口令或播放量等关键转化信息，但不要遮挡核心画面。
- 结尾可加入主页引导文案，引导用户回到主页继续观看后续内容。
- 做口令推广时，可在画面中突出短剧 App 名称和口令，帮助用户完成搜索。

## TikTok 内容审核红线

**年龄分级管控：**

- 禁止出现色情、血腥、暴力、性暗示、烟酒等 18+ 年龄段禁忌内容。

**原创度风险：**

- 不要直接搬运视频。
- 不要只做简单去重、加水印或滤镜。

**规避处理建议：**

- 动态模糊处理高速移动画面。
- 多重马赛克叠加关键区域。
- 可定制智能识别遮罩工具。

<Danger>
  多次被提示视频内容有问题，可能会被限流甚至封号。
</Danger>
