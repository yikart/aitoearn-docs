## 功能特性及实用信息

| 项目 | 说明 |
| --- | --- |
| 安排帖子 | 受 X/Twitter 规则限制，每次只能安排发布到 1 个 X/Twitter 账户；不允许重复发布相同内容。 |
| 串文 | 支持创建 X/Twitter 串文，单条串文最多包含 25 条子帖；创建串文建议在网页端完成。 |
| 转发 | 支持从 X/Twitter 信息流安排转发。 |
| 标签 / 提及 | 如需提及其他 X/Twitter 账号，请输入准确的 @handle；受 API 限制，第三方工具无法自动补全账号。 |
| 图片替代文本 | 支持为图片添加替代文本。 |
| 每日发布限制 | 未验证账号每 24 小时最多 50 条；已验证账号每 24 小时最多 100 条。 |
| 字符限制 | 免费账号每条最多 280 个字符；Basic、Premium 与 Premium+ 账号每条最多 25,000 个字符。 |
| 链接预览 | 时间线仅展示前 280 个字符；如需显示链接预览，请将 URL 放在前 280 个字符内。 |
| 话题标签 | 编辑器中输入所需标签，发布后会自动转为可点击标签。 |
| 暂不支持 | 暂不支持创建 X/Twitter 投票。 |

## X/Twitter 的图片、视频和 GIF 规格

| 分类 | 视频 | 图片 | GIF |
| --- | --- | --- | --- |
| **每条帖子允许数量** | 最多 1 个视频 | 最多 4 张图片 | 最多 1 个 GIF |
| **视频时长** | 0.5 秒至 140 秒；超过 140 秒的视频需在 X/Twitter 原生端发布，且账号需订阅 Premium | 不适用 | 不适用 |
| **文件大小** | 最大 512MB | 最大 5MB | 最大 15MB |
| **尺寸** | 暂无 | 最大 8192 x 8192 像素 | 最大 1280 x 1080 像素；总像素不超过 3 亿 |
| **支持的文件格式** | MP4、MOV、AVI、M4V；纯音频 MP4 不支持，MP4 文件必须包含视频轨道 | JPG、PNG、HEIC、WebP | GIF |
| **自定义缩略图** | 不支持 | 不适用 | 不适用 |
| **自动播放** | 不支持，推广广告除外 | 不适用 | 不适用 |
| **最佳帧率 / 帧数** | 60 FPS 或更低 | 不适用 | 最多 350 帧 |

- GIF 建议控制在最大 1280 x 1080、最多 350 帧、总像素不超过 3 亿，避免画质损失或发布失败。
- 实际发布以 Aitoearn 页面校验结果为准。
