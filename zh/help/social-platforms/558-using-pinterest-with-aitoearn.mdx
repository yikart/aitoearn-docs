## 功能特性及实用信息

| 项目 | 说明 |
| --- | --- |
| 安排帖子发布 | 支持安排 Pinterest Pin 发布。 |
| 标签 / 提及 | 暂不支持在已安排的 Pin 中提及或标记 Pinterest 个人资料，也暂不支持在 Pinterest 上标记主题。 |
| 标签 | Pinterest 不支持话题标签超链接，因此发布到 Pinterest 的话题标签无法点击。 |
| 每日发帖限额 | 已验证邮箱的用户每 24 小时最多发布 25 条；未验证邮箱的用户每 24 小时最多发布 5 条。 |
| 字符限制 | 每篇 Pin 最多 500 个字符。 |

## Pinterest 的图片、视频和 GIF 规范

| 项目 | 视频 | 图片 | GIF |
| --- | --- | --- | --- |
| 每个帖子允许数量 | 最多 1 个 | 最多 1 张 | 最多 1 个 |
| 视频时长 | 4 秒至 15 分钟 | 不适用 | 不适用 |
| 文件大小 | 最大 1GB | 最大 10MB | 最大 3MB |
| 尺寸 / 宽高比 | 建议 1:1、2:3、4:5 或 9:16 | 不适用 | 不适用 |
| 支持的文件格式 | MP4、MOV、AVI、M4V | JPG、PNG、WebP、HEIC | GIF |
| 自定义缩略图 | 支持 | 不适用 | 不适用 |
| 自动播放 | 支持 | 不适用 | 支持 |
| Canva | 支持 | 支持 | 不适用 |
| Giphy | 不适用 | 不适用 | 支持 |
| 替代文本 | 不适用 | 支持 | 不适用 |

- 实际发布以 Aitoearn 页面校验结果为准。
