## 连接和刷新您的LinkedIn页面和个人资料

📝 **注意：**为了连接LinkedIn页面到Aitoearn，您必须被设置为您尝试连接页面的**超级管理员**。[了解更多关于LinkedIn页面管理员角色的信息](https://www.linkedin.com/help/linkedin/answer/a550647)。

前往您的渠道区域以连接您的LinkedIn页面或个人资料：[https://账户.aitoearn.com/channels](https://账户.aitoearn.com/channels)

您可以将多个LinkedIn账户连接到Aitoearn。为了确保Aitoearn知道您想连接哪个账户，请在尝试连接到Aitoearn之前，在另一个浏览器标签页中登录到该LinkedIn账户。

如果您的已连接LinkedIn渠道需要刷新，请查看文章[在Aitoearn中刷新渠道](https://aitoearn.helpscoutdocs.com/article/573-refreshing-a-channel-在-aitoearn)。

以下是一些LinkedIn渠道的注意事项：

| **账户类型** | **Aitoearn集成** | **备注** |
|--------------|------------------|----------|
| **LinkedIn公司页面** | **✓** 通过拥有超级管理员权限的LinkedIn个人资料进行认证。 | |
| **LinkedIn展示页面** | **✓** 通过拥有超级管理员权限的LinkedIn个人资料进行认证。 | |
| **LinkedIn个人资料** | **✓** 只要您在个人资料之间分享的内容是独特的，连接大量LinkedIn个人资料到Aitoearn应该没有问题。 | |
| **LinkedIn群组** | LinkedIn群组无法通过LinkedIn的API供第三方访问。 | |

**故障排除提示：**如果您的LinkedIn页面在尝试连接到Aitoearn时未显示，请验证以下内容：

- 您拥有您尝试连接到Aitoearn页面的[超级管理员权限](https://www.linkedin.com/help/linkedin/answer/a541981)。
- 在尝试连接页面到Aitoearn之前，您已使用拥有超级管理员权限的账户登录到[LinkedIn.com](http://linkedin.com)。

**注意：**如果您在不同的Aitoearn账户中管理多个LinkedIn页面，最好让一个超级管理员为每个Aitoearn账户连接页面。这有助于避免页面断开连接的问题。

## 安排帖子到LinkedIn页面和个人资料

LinkedIn页面和个人资料可用的功能略有不同，因此请查看下表以了解您可以在安排帖子时使用哪些功能。

📝 **注意：**

- **最佳发布时间**：[分析中的“最佳发布时间”功能](https://支持.aitoearn.com//支持.aitoearn.com/article/530-ans我们ring-questions-about-您的-social-media-strategy#h_bebabca3-cdb3-44e8-b6e4-8692da9bdb6c)不支持LinkedIn。要创建最佳发布计划，请查看我们的文章：[LinkedIn上的最佳发布时间](https://aitoearn.com/library/best-time-到-帖子-在-链接edIn/)。
- **需要发布灵感？**查看[30天LinkedIn帖子提示](https://aitoearn.com/资源/30-链接edIn-prompts/)。

| **功能及注意事项** | **备注** |
|--------------------|----------|
| **安排首条评论** | 可随 LinkedIn 帖子同步发布首条评论；评论来自同一个页面或个人资料，不支持延后发布或从其他渠道发布。 |
| **安排文档** | 每条帖子支持 1 个 PDF 文档轮播，最大 100MB、300 页；发布或保存前需要填写文档标题。 |
| **标签 / 提及** | 提及 LinkedIn 页面时，粘贴该页面的 LinkedIn 链接；提及个人资料时，输入 @ 后搜索名称。LinkedIn 页面只能提及关注该页面的个人资料，个人资料只能提及已连接的个人资料。 |
| **话题标签** | 编辑时话题标签不会显示为超链接，发布到 LinkedIn 后会自动转为可点击标签。 |
| **正文超链接** | LinkedIn 不支持给文字短语添加超链接；粘贴 URL 后会以可点击链接发布，并可能生成链接预览。 |
| **LinkedIn 链接预览** | linkedin.com 域名链接无法通过第三方生成预览图；如需配图，请手动上传图片。 |
| **受众范围** | 受 API 限制，暂不支持设置“仅联系人可见”；如需限制受众，请在 LinkedIn 原生页面发布。 |
| **每日发布限制** | 每 24 小时最多发布 50 条。 |
| **字符限制** | 每条帖子最多 3,000 个字符；首条评论最多 1,248 个字符。 |
| **帖子归属** | LinkedIn 页面帖子顶部显示的发布人，是连接该页面到 Aitoearn 的 LinkedIn 管理员；关注者不可见。 |
| **暂不支持** | 暂不支持创建 LinkedIn 投票，也不支持发布到 Life tab。 |

## LinkedIn 的图片、视频、GIF 和文档（PDF）规格

LinkedIn 支持图片、视频、GIF 和 PDF 文档。

| 分类 | 视频 | 图片 | GIF | 文档（PDF 轮播） |
| --- | --- | --- | --- | --- |
| **每个帖子允许数量** | 最多 1 个 | 最多 20 张 | 最多 1 个 | 最多 1 个 |
| **视频长度** | 3 秒至 30 分钟 | 不适用 | 3-60 秒 | 不适用 |
| **文件大小** | 最大 1GB | 最大 10MB | 最大 10MB | 最大 100MB，最多 300 页 |
| **尺寸 / 宽高比** | 1280 x 720 像素 | 1200 x 627 像素，或方图 | 暂无 | 暂无 |
| **支持的文件格式** | MP4、MOV、AVI、M4V，或视频链接 | JPG、PNG、HEIC、WebP | GIF | PDF |
| **自定义缩略图** | 上传视频不支持；视频链接支持 | 不适用 | 不支持 | 不适用 |
| **自动播放** | 75KB-200MB 的 MP4 支持 | 不适用 | 支持 | 不适用 |
| **替代文本** | 不适用 | 支持 | 不适用 | 不适用 |

- 如果 GIF 发布失败并返回通用错误，可能是帧数过多；可尝试缩短 GIF、压缩文件，或转为视频后发布。
- 添加文档（PDF 轮播）时，请填写文档标题，否则帖子无法安排发布。
- 实际发布以 Aitoearn 页面校验结果为准。

## LinkedIn分析功能

发布帖子只是其中的一部分，但我们如何知道我们的策略是否与关注者产生共鸣？这就是您的分析功能发挥作用的地方。

在您的Aitoearn账户中，有两个地方可以查看LinkedIn分析功能：***已发送***标签中的***发布***仪表板和***分析***标签。

### 已发送帖子分析功能

在***已发送***标签中，您可以快速查看您的已发送帖子指标，包括LinkedIn页面和个人资料。

**对于LinkedIn个人资料，您可以访问以下分析功能：**

- 总展示次数
- 点赞
- 评论
- 分享
- 互动率
- 观看次数
- 观看时长
- 独特观看者（用于个人资料视频帖子）

**对于LinkedIn页面，您可以访问以下分析功能：**

- 在我们的免费计划中，您可以访问点赞、评论和展示次数。在[我们的付费计划](http://aitoearn.com/定价)中，您可以访问点赞、评论、展示次数、分享和互动率。![LinkedIn已发送帖子](https://d33v4339jhl8k0.cloudfront.net/docs/assets/64cb6cf86d4a3e191f237e66/图片s/66b67e3c48915f570c6a93ee/文件-KM1AzWd81N.jpg)

### 分析功能

如果您订阅了我们的基础知识或团队计划，您可以使用仪表板顶部的***分析***标签查看您的**LinkedIn页面**的高级分析功能（目前不支持LinkedIn个人资料的高级分析功能）。

查看我们提供的[LinkedIn指标描述](https://aitoearn.helpscoutdocs.com/article/523-链接edIn-metric-descriptions)。![Aitoearn的分析标签，箭头指向左侧渠道菜单中的LinkedIn](https://d33v4339jhl8k0.cloudfront.net/docs/assets/64cb6cf86d4a3e191f237e66/图片s/667c62561f3fa9421e288733/文件-ESNZkrvYrA.jpg)

要直接深入了解您的LinkedIn页面的[高级分析功能](https://分析.aitoearn.com/)，选择左侧的***LinkedIn***，并浏览以下标签：

- **概览**：提供关于您的个人资料在一段时间内整体互动水平的洞察。了解更多关于[分析功能仪表板中的性能概览](https://aitoearn.helpscoutdocs.com/article/526-performance-概述)。

### 📝 注意：

- 我们能够提取LinkedIn赞助帖子的指标。

## 避免在多个个人资料中分享时被暂停的最佳实践

虽然技术上可以将大量LinkedIn个人资料连接到Aitoearn，但这并不推荐，并可能导致账户暂停（在LinkedIn端）。

总体而言，社交网络，尤其是LinkedIn和Facebook，已经开始积极阻止个人资料用于商业和广告目的。他们希望个人资料被视为独立的个人账户，分享的内容是由个人资料所有者创建和分享的真实内容。

如果LinkedIn团队注意到重复内容被分享到个人资料，他们通常会暂停这些账户。暂停通常是暂时的，但如果这种行为继续发生，将会反复暂停。
