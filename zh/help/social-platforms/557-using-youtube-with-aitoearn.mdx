> 注意：YouTube 服务目前处于内测阶段，功能与权限可能调整。

## 连接要求
- 需使用 YouTube 频道所有者的 Google 账号登录并完成连接（品牌账号管理员暂不支持）。
- 请完成 YouTube 邮箱验证：未验证的账户 24 小时内最多发布 10 条，且描述中无法添加外部链接；验证后不受此限制。

## 功能特性及实用信息

| 项目 | 说明 |
| --- | --- |
| 安排帖子发布 | 支持安排 YouTube Shorts 发布。 |
| 每日发帖限额 | 未验证邮箱地址的用户每天最多发布 10 条；已验证邮箱地址的用户每天发布数量不限。 |
| 字符限制 | 标题限 100 个字符，描述限 5,000 个字符。 |
| 标签 | 可在编辑器中输入标签；帖子发布后，标签会像原生平台标签一样自动添加超链接。 |
| 缩略图 | 目前暂不支持为 YouTube Shorts 选择自定义缩略图。 |

## 发布内容要求
| 内容 | 纯文字 | 图片 | 视频 |
| --- | --- | --- | --- |
| 支持情况 | x | x | ✓ |

YouTube Shorts 视频规格：

| 项目 | 视频 |
| --- | --- |
| 每条内容允许数量 | 最多 1 个视频 |
| 视频时长 | 最长 3 分钟 |
| 文件大小 | 10GB 或更小 |
| 尺寸 / 宽高比 | 方形 1:1 或竖屏 9:16；推荐竖屏 |
| 支持的文件格式 | MOV、MP4、MPG、MPEG、AVI、WebM |
| 自定义缩略图 | 不支持 |
| Giphy 和 Canva 集成 | 不支持 |
| 替代文本 | 不支持 |

- 实际发布以 Aitoearn 页面校验结果为准。
