## 功能特性及实用信息

| 项目 | 说明 |
| --- | --- |
| 安排帖子发布（网页） | 支持在网页端安排 TikTok 帖子发布。 |
| 安排帖子发布（移动端） | 支持在移动端安排 TikTok 帖子发布。 |
| 标签 / 提及 | 如需标记或提及其他 TikTok 账号，请输入准确用户名；发布后会自动转为可点击链接。 |
| 标签 | 每篇帖子最多使用 5 个话题标签；编辑器中不显示超链接，发布到 TikTok 后会显示为超链接。 |
| 每日发帖限额 | 每 24 小时最多发布 25 条帖子。 |
| 字符限制 | 每篇帖子最多 2,200 个字符。 |
| 音乐、热门音频、贴纸或投票 | 受 API 限制，暂不支持直接添加 TikTok 音频库、热门音频、贴纸或投票。 |

## TikTok 发布内容要求

| 内容 | 纯文字 | 图片 | 视频 |
| --- | --- | --- | --- |
| 支持情况 | x | ✓ | ✓ |

| 项目 | 视频 | 图片 |
| --- | --- | --- |
| 每条内容允许数量 | 最多 1 个 | 最多 10 张 |
| 视频时长 | 3 秒至 10 分钟 | 不适用 |
| 文件大小 | 最大 1GB；宽高均需 ≥360px | 最大 20MB |
| 尺寸 / 宽高比 | 宽高均需 ≥360px | 最大分辨率 1080 x 1920 或 1920 x 1080 |
| 支持的文件格式 | MOV、MP4、WebM | jpg、jpeg、webp |
| 自定义缩略图 | 支持从视频中选择帧作为个人主页缩略图 | 不适用 |
| 最佳帧率 | 23 FPS 至 60 FPS | 不适用 |
| 信息流自动播放 | 支持 | 不适用 |
| Canva 集成 | 不支持 | 支持 |
| 替代文本 | 暂不支持为视频添加替代文本 | 受 API 限制，暂不支持 |
