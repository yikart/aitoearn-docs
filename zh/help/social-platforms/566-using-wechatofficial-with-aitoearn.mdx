## 内容发布要求
适用于文章发布、图片发布、纯文字发布。

| 项目 | 要求 |
| --- | --- |
| 标题长度 | 最多 64 个字符 |
| 正文长度 | 最多 20,000 个字符 |
| 图片数量 | 最多 20 张 |
| 图片大小 | 单张图片最大 10MB |
| 图片格式 | JPG、JPEG、PNG、GIF、BMP |
